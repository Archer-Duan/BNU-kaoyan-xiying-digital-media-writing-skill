# 第四批材料分析：热点大盘与分类图

## 材料定位

- 文本大盘提供了较完整的知识范围和初步层级，是专题库的内容底盘。
- 分类图提供横向覆盖检查，包含技术、媒介、题材/体裁、电影类型、国际传播、文化价值、理论背景、叙事理论、传播理论、IP与受众、产业现象等视角。
- 二者不能直接合并成一棵树，因为其中混合了研究对象、分析阶段、理论工具、热点现象、作品类型和政策价值等不同维度。

## 核心改造：主专题 + 多维标签

每份材料只设一个便于归档的主专题，但允许拥有多个检索标签。这样 XR、AIGC、跨媒介叙事、IP、媒介融合等跨域主题不会因固定在单一目录而丢失关联。

### 维度一：研究对象

- 电影
- 广播电视与网络视听
- 动画
- 游戏
- 数字媒体/互动影像
- 跨对象综合议题

### 维度二：分析阶段

- 创制：技术、生产、制作、工业流程
- 作品：文本、形式、内容、叙事、体验、美学
- 传播：媒介、平台、渠道、国际传播
- 接受：受众、社群、文化、市场、消费
- 价值与治理：文艺思想、政策、伦理、行业治理
- 历史与演进：概念史、媒介史、产业史、创作历程

这六个阶段是阅读论文、整理专题、拆解题目、生成提纲和批改答案共同使用的主框架。

### 维度三：机制或理论视角

- 技术机制
- 媒介与平台机制
- 叙事机制
- 视听与审美机制
- 产业与商业机制
- 传播与文化机制
- 受众与参与机制
- 政策、伦理与治理机制

### 维度四：题目动作

- 定义/辨析
- 特征/类型
- 历程/演变
- 机制/原因
- 影响/价值
- 比较/异同
- 矛盾/风险/挑战
- 对策/路径/趋势
- 案例分析
- 创作或产品方案

### 维度五：材料时效

- 基础知识：概念、经典理论、历史流程，可长期使用。
- 常青热点：媒介融合、IP、参与式文化、国际传播等，需要定期补案例。
- 年度热点：政策、行业报告、年度现象和最新作品，需要标注年份。
- 前沿议题：AIGC、智能体、3D 高斯溅射、空间智能等，事实和术语必须重点核验。

## 建议的七个主专题域

1. **技术、媒介与智能创制**
   - 网络与基础设施：5G、云计算、流媒体、大数据、算法。
   - 影像技术：超高清、高帧率、3D、IMAX、声音系统。
   - 图形与生产：CG/CGI、渲染、游戏引擎、数字资产、虚拟制片、动作捕捉、VFX/SFX。
   - 交互与沉浸：HCI、互动影像、XR/VR/AR/MR、空间计算、LBE、具身交互。
   - 智能化：AI、GenAI、AIGC、多模态、智能体、数字人、空间智能、具身智能。

2. **影视、动画与游戏工业**
   - 电影工业流程与数智化转型。
   - 动画技术、动画工业与中国动画学派。
   - 游戏工业、影游融合、游戏化设计、严肃游戏与心流。
   - 数字资产、IP生命周期和跨产业协同。

3. **文本、类型、叙事与体验**
   - 电影、电视剧、网络剧、微短剧、综艺、纪录片等形态。
   - 现实、幻想、主流、女性、喜剧、悬疑等题材/类型。
   - 线性、非线性、数据库、互动、智能、涌现与跨媒介叙事。
   - 沉浸、触觉、空间、身体、奇观、工业与共同体等美学视角。

4. **广播电视、网络视听与平台融合**
   - 网络视听产业、未来电视、大视听和精品化。
   - 长短视频、直播、微短剧、剧综联动、台网联动、跨屏互动。
   - 全媒体、融媒体、媒体深度融合、智能媒体。
   - 文旅融合、数实融合及线上线下场景协同。

5. **传播、国际流动与平台社会**
   - 传播基础理论与适用范围。
   - 国际传播、跨文化传播、全球在地化、文化出海。
   - 平台分发、算法推荐、注意力经济、分众与长尾传播。
   - 数字鸿沟、算法偏见、数字劳动、媒介物质性等前沿问题。

6. **受众、IP、参与文化与市场**
   - 接受美学、参与式文化、共创美学与体验经济。
   - IP开发、IP改编、跨媒介叙事、电影宇宙。
   - 粉丝文化、粉丝经济、圈层文化、迷影文化。
   - UGC、二创、发行、分账、院线、电影节与商业模式。

7. **中国影视文化、文艺思想与政策治理**
   - 人民文艺、以人民为中心、守正创新、两创。
   - 新主流、温暖现实主义、新大众文艺、共同体美学。
   - 高质量发展、新质生产力与“人工智能+”。
   - 超高清、微短剧文旅、VR电影等年度政策议题。
   - 技术伦理、版权、真实性、主体性和文化治理。

## 需要避免的错误层级

- “媒介融合”可作为重要背景和分析逻辑，但影游融合、数实融合、跨媒介叙事不宜全部被定义为它的严格下位概念；应标为相关或交叉议题。
- 新媒体、数字媒体、网络媒体和社交媒体不是在所有理论语境下都能按单一包含关系排列，应分别定义并记录语境。
- GenAI 指生成式人工智能，AIGC 指人工智能生成内容，二者相关但不等同。
- XR 提供沉浸和交互的技术条件，不意味着所有 XR 作品都自动形成高质量沉浸或强交互。
- 微短剧与网络剧、动画产业与影视工业的归属关系应按考试口径、政策口径和研究语境分别说明，不能只保留一个绝对判断。
- “北师大是否常考”“非数媒方向掌握到什么程度”属于考试路由规则，不属于学科概念本身。
- “阅读某报告/某教授论文”属于来源清单，不应成为分类节点。

## 专题卡结构

每个专题最终整理为以下字段：

1. 专题名称、别名和边界。
2. 基础概念与容易混淆的概念。
3. 发展历程与关键转折。
4. 对象标签、分析阶段、理论视角、院校方向。
5. 可检索子问题：是什么、为什么、如何发生、产生什么影响、有哪些问题、如何发展。
6. 核心观点：正面机制、负面风险、矛盾关系、未来路径。
7. 考场材料：深描案例、并列案例、理论、政策、可写表达。
8. 材料状态：已核验、来自用户材料、待核验、禁止使用。
9. 可迁移真题与邻接专题。
10. 三类输出：名词解释、简答、论述；简答和论述共用框架但控制复杂度与篇幅。

## 题目路由示例

### “人工智能对游戏开发、游戏体验和市场格局的影响”

- 对象：游戏。
- 驱动变量：AI/AIGC。
- 分析阶段：创制、体验、产业。
- 题目动作：影响分析。
- 检索专题：智能创制、游戏工业、人机交互、受众体验、平台与市场。

### “IP跨媒介叙事产业的挑战与路径”

- 对象：IP与跨媒介内容。
- 分析阶段：文本叙事、产业协同、受众参与。
- 题目动作：问题—原因—路径。
- 检索专题：跨媒介叙事、IP产业、参与式文化、版权治理。

### “文化出海如何从走出去转向走进去”

- 对象：中国视听作品。
- 分析阶段：内容创作、平台传播、海外接受。
- 理论视角：跨文化传播、全球在地化、共情传播。
- 题目动作：范式变化及其对创作的要求。
