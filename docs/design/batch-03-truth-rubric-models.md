# 第三批材料分析：真题、评分标准与范文

## 材料角色

- `真题研究.xlsx`：用于建立院校、科目、年份、方向与题型画像，不将表内的个人考点标注直接视为权威结论。
- 五张评分截图：用于提炼整张专业课试卷的分档标准。截图中的 95–112、120–133、130–142 是整卷区间，不直接等同于单篇论述题得分。
- `pasted-text.txt`：含 13 篇修订文章，可作为结构和表达校准样本；其中的学者、数据、案例与引文必须重新核验，不能直接作为事实库。

## 院校与科目画像

### 北师大：主目标

#### 719（影视戏剧史论）

- 2024–2025：名词解释、简答、方向化论述并存；2026 仍保留三类题，但题量发生变化。
- 题目覆盖电影史论、戏剧史论、传播与数字媒体基础、当代热点。
- 论述重心偏向：现象分析、文化传播、创作趋势、产业问题、媒介技术影响。
- 近年数媒高频母题：AIGC、XR/VR、跨媒介叙事、网络视听、文化出海、传统文化数字化、动画/游戏。
- 近年电影高频母题：现实主义、传统文化改编、电影工业与技术、网络平台、后电影、商业大片。

#### 842（影视戏剧实践）

- 2024–2026 的结构较稳定：5 个名词解释、2 个简答、按方向作答的 2 个论述/实践题。
- 与 719 相比，更强调创作、应用、产业和实践场景。
- 数媒方向反复出现：AI 与游戏、XR/VR、影游/跨媒介、非遗数字化方案、文旅融合。
- 电影方向反复出现：新力量导演、后电影、传统文化改编、现实主义、数字技术与电影产业。
- 2023 及以前的 904 只作为改革前趋势参考，不能与当前 842 题型权重直接合并。

#### 719 与 842 的联动训练

- 同一专题整理两套检索问题：
  - 719：概念、历程、现状、原因、影响、问题、趋势。
  - 842：创作机制、技术应用、产业流程、产品方案、场景落地、治理路径。
- 同一材料进入答案时也要双重改写：一版成为史论/热点分析论据，一版成为实践/产业案例。

### 华东师大 668：辅助迁移题库

- 2019–2025 的样本主要是长答案，没有北师大式名词解释组合。
- 2024–2025 为 4 选 2 的 35 分简答与 2 选 1 的 80 分论述；2022 为 50 分简答与 100 分论述。
- 题目常直接给出媒介现象、技术情境或案例，要求从视听艺术、数字媒体、传播或创作角度展开。
- 适合训练双任务覆盖、长论证和陌生材料迁移；不用于推断北师大的题量、时间和字数。

## 写作容量配置

默认按院校、科目、年份独立配置，不设全局唯一字数：

- 北师大 719（2026 口径）：名词解释 200–240 字；简答 500–600 字；论述 1300–1500 字。
- 北师大 842（2026 口径）：名词解释 240–300 字；简答 700–800 字；论述 1300–1500 字。
- 华东师大 668：按具体年份题面要求或分值动态计算，不套用北师大字数。

## 评分规尺

### 先做三道门槛检查

1. 任务覆盖：问法中的每一个动作和限定对象都得到回答。
2. 事实完整性：学者、作品、政策、数据、引文都可追溯；无法核验则降级为稳健表达或删除。
3. 考场适配：符合该科目、年份、题型的字数与时间预算。

### 八个评价维度

1. 标题与中心论点是否准确、明确并覆盖题目。
2. 分论点角度是否准确，板块排序是否自然，能否共同支撑中心论点。
3. 小标题和段首主旨句是否真正承担分论点功能。
4. 论据是否精准匹配，能否组合深描案例与并列案例。
5. 是否存在“论点—论据—论证—回扣”，而非案例罗列。
6. 理论、评述句与个人判断是否建立在材料分析之上。
7. 结尾是否总结、呼应并适度提升，不另起新论题。
8. 句子、段落与衔接是否清楚、准确、无明显语病。

### 分档映射

- 四类：框架不完整、论点不明或严重偏题；标题/论点有明显语病；案例失配；完成度明显不足。
- 三类：有标题和基本结构，角度大体不偏，但板块顺序一般；案例匹配不稳；评述与论证不足；模板痕迹重。整卷约 95–112。
- 二类：标题准确，中心论点能够整合分论点；宏观板块形成共振；段落论证清楚；案例与理论准确；结尾完整；语言干净。整卷约 120–133。
- 一类：在二类基础上，问法回应精确，角度自然且有洞见；详略得当，兼有深入案例与并列材料；评述言之有物，能形成自己的判断；结尾提升得当。整卷约 130–142，再高不宜机械承诺。

单篇答案只输出“维度诊断 + 等级倾向 + 该题分值下的暂定区间”。在获得真实批改样本前，不把整卷分档直接换算为单题精确分数。

## 十三篇范文的整体校准结论

### 可保留为正向范式

- 普遍采用“标题—中心论点—三板块—结论”，外部结构清晰。
- 多数小标题能概括分析角度，案例密度高。
- 较好的文章能做到一段内先提出判断，再给案例并回到题目。
- 以下题目与结构匹配度较高：
  - AIGC 的文化多样性、审美同质化与伦理悖论。
  - 粉丝文化的参与性、圈层性与情感经济。
  - 在地化叙事从地域符号、共通经验到集体记忆的机制链。
  - 文化综艺针对历史浅表、形式同质、接受被动的逐项回应。

### 不能直接固化为高分答案的部分

- 13 篇中只有“温暖现实主义”约 1369 字，落在北师大论述 1300–1500 字范围；其余约 1551–1876 字，更适合作为扩展复习版，必须另做考场压缩版。
- 开头大量使用“近年来 + 行业数据 + 三分法”，结尾大量复述三板块，易形成三类文所说的模板化。
- 多篇存在案例密度高但论证不足的问题：案例说明“发生了什么”，未充分说明“为什么能证明本段判断”。
- 大量具体数据、政策表述、机构合作、作品制作细节、学者引文没有材料清单，必须进入核验队列。
- 个别理论只是点名装饰；未经核验的戴锦华引语、汤姆·多德“蓝图式规划”等不得进入正式答案。
- 个别文章出现任务覆盖偏差：
  - IP 跨媒介题的标题和小标题突出路径，对“核心挑战”的显性回应不足。
  - 文化出海题需要让每一板块同时呈现“传播范式变化—对创作的内在要求”。
  - 超高清题混入 AIGC、营销和跨屏案例，需证明与超高清技术之间的直接因果，避免概念漂移。
  - 中国动画题对“百年历程”的阶段性呈现不足。
  - 媒体深度融合题对“未来发展”的独立回答偏弱。
  - 温暖现实主义稿含学习批注，且部分理论引语需要核验，不能视为成稿。

## Skill 设计新增规则

1. 增加 `exam_profile`：学校、科目代码、年份、方向、题型、分值、字数、时间。
2. 增加 `task_coverage_matrix`：逐项列出题目动词、对象、范围、时间、案例要求，并在提纲和成文后各检查一次。
3. 增加 `evidence_status`：已核验、仅见于用户材料、待核验、禁止使用。
4. 增加 `dual_output`：扩展复习版可以 1600–2000 字；北师大考场版必须压缩到对应科目范围。
5. 增加 `model_calibration`：范文只按结构、论证、表达、事实四层拆开学习，不整篇模仿。
6. 批改顺序固定为：任务覆盖 → 中心论点 → 宏观结构 → 段落论证 → 材料真实性 → 语言与考场适配。
