# 考研影视论述训练与写作 Skill

这是一个面向中国影视、广播电视、网络视听与数字媒体考研的 Codex Skill 开发仓库，重点适配北京师范大学 719/842，并以华东师范大学 668 作为辅助训练题库。

## 项目结构

```text
skill/
  kaoyan-audiovisual-writing/   可安装的 Skill 本体
docs/
  design/                       真题、评分、热点分类与行为测试设计记录
tools/
  docx/                         写作方法论文档提取与检查工具
  xlsx/                         真题表格检查工具
```

Skill 入口位于 `skill/kaoyan-audiovisual-writing/SKILL.md`。

## 当前能力

- 名词解释、简答、论述三类题的审题与写作；
- 真题拆解和提纲生成；
- 基于材料生成考场版与扩展复习版；
- 论文阅读、专题卡整理与概念讲解；
- 答案批改、结构重写与事实风险检查；
- 按院校风格模拟出题和递进训练。

## 材料边界

原始教材、论文、真题文档和个人知识库没有复制到仓库。它们可能包含版权内容、个人资料或持续变化的数据，应在本地的 `private-sources/` 中管理，或者通过明确授权的外部知识库按需读取。

## 开发状态

当前为 v0。下一阶段使用一个完整热点专题及其核心论文做端到端测试，再根据真实表现修订检索、材料转写和评分规则。
