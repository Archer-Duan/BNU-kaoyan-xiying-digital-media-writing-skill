# 写作方法论

## 统一逻辑

阅读论文、整理专题、生成答案和批改答案使用同一套框架：

```text
题目或专题问题
→ 可检索子问题
→ 观点与材料
→ 中心论点和分论点
→ 段落论证
→ 任务覆盖与质量检查
```

专题不是材料仓库，而是观点进入考场答案前的中转站。提取材料时始终追问“这能回答什么题、支撑什么判断、应该怎样改写”。

## 统一中间结构

阅读、整理、写作和批改不得各自使用一套互不相干的框架。所有模式共用以下四种对象；它们是思考工具，不要求每次都原样展示给用户。

### 1. 问题卡

```text
考试配置：学校 / 科目 / 方向 / 题型 / 分值 / 字数与时间
研究对象：
命令动词：
限定条件：
显性任务：T1 / T2 / ...
隐含任务：必要的概念界定、比较基准或评价尺度
核心矛盾或关系：
可检索子问题：Q1 / Q2 / ...
证据要求：案例 / 理论 / 历程 / 政策 / 数据
```

一道题可以有多个任务，但每个任务至少应对应一个子问题。子问题必须能指导检索或材料筛选，不能只是把原题换一种说法。

### 2. 材料单元

```text
材料编号：E1 / E2 / ...
回答的子问题：
可用判断：
材料类型：观点 / 案例 / 理论 / 政策 / 数据 / 反例
事实或依据：
解释机制：它为什么能支持该判断
适用对象与边界：
考场转写：
来源定位与核验状态：
```

没有“回答的子问题”和“解释机制”的摘录只是资料片段，不能直接进入专题或答案。一个材料单元优先承载一个主要判断；同一材料可以复制关联到不同子问题，但必须分别说明其证明关系。

### 3. 论证单元

```text
论证编号：A1 / A2 / ...
覆盖任务：T?
中心分论点：可判断、可论证的完整命题
使用材料：E? / E?
论证桥梁：材料如何证明分论点
限制、反面或条件：必要时填写
题目回扣：这一判断最终回答了什么
```

论证单元是段落的逻辑底稿。只列“技术、内容、传播”不是分论点；只写案例名称也不是论证。材料不足以支撑判断时，应缩小判断、补充材料或删除该角度。

### 4. 成品结构

```text
中心论点：
板块顺序：A? → A? → A?
板块关系：并列 / 递进 / 因果 / 流程 / 正反 / 微观到宏观
任务覆盖：T1 → A?；T2 → A?
篇幅分配：引论 / 各板块 / 结尾
版本策略：考场保留项 / 复习扩展项
```

成品结构不是先选“三段式”再填内容，而是从任务覆盖和有效论证单元中长出来。三至四板块是常见结果，不是必须凑齐的数字。

## 四种模式的同构转换

| 模式 | 输入 | 核心操作 | 输出 |
|---|---|---|---|
| 阅读论文 | 论文问题与原文 | 识别作者任务，拆出可追溯材料单元 | E1、E2……及可回答子问题 |
| 整理专题 | 多篇论文与已有材料单元 | 按子问题归并、去重、比较和补缺 | 专题问题卡、材料池和候选论证单元 |
| 答题写作 | 题目与可用材料 | 建问题卡，选择材料，搭建论证单元 | 中心论点、提纲和答案 |
| 批改答案 | 原题与学生答案 | 反向复原问题卡、论证单元和材料链 | 覆盖缺口、论证断点和重构方案 |

因此，批改发现的缺陷必须能回溯到具体环节：知识材料不足、审题任务遗漏、角度选择失衡、论证桥梁缺失或表达未完成。不能把所有问题都归结为“语言不够好”。

## 阶段门槛

按以下门槛决定是否继续生成：

1. **分析门槛**：研究对象、命令动词、限定和显性任务已经识别；否则先澄清或声明合理默认。
2. **材料门槛**：每个关键分论点至少有一项可追溯材料或稳定知识，并能说明证明关系；否则标记材料缺口，只给暂定结构。
3. **结构门槛**：候选论证单元能够覆盖全部任务，且层级相近、相互区分；否则调整分论点而不是直接润色。
4. **成文门槛**：字数、时间和版本目标已经确定；否则采用对应考试配置的默认值并明示。

门槛不是要求向用户展示冗长过程。若信息充分，可以在内部快速完成；若材料冲突、题意含混或用户正在训练审题，则应展示相关问题卡或材料缺口。

## 题目分析矩阵

拿到题目后先识别：

1. **考试配置**：学校、科目代码、年份、方向、题型、分值和字数。
2. **研究对象**：题目真正要求讨论的概念、作品、媒介、产业或现象。
3. **命令动词**：解释、简述、分析、比较、评价、论述、探讨、设计等。
4. **限定条件**：时间、地域、媒介、题材、案例数量、专业视角等。
5. **关系或矛盾**：技术与艺术、传统与创新、多样性与同质化、流量与价值等。
6. **任务数量**：题目包含几个必须分别回答的动作；并列问法不得遗漏。
7. **证据要求**：是否要求结合具体作品、理论、政策、发展历程或行业实践。
8. **时态与语态**：现状、历史、未来；解释、评价、建构或提出方案。

把结果改写为可检索子问题，例如：

- 这个概念是什么，与邻近概念有什么区别？
- 它如何产生和演变？
- 通过什么机制影响创作、文本、传播、接受或产业？
- 主要价值、问题和矛盾是什么？
- 哪些案例能证明这些判断？
- 未来路径应针对什么原因和环节？

建立子问题后，为每个显性任务标注其对应关系。若某个任务没有子问题，说明审题不完整；若某个子问题不能服务任何任务，应判断它是否只是无关扩展。

## 候选角度生成

使用“研究对象 × 分析角度”的交叉法生成候选分论点。分析角度包括：

- 创制：技术、生产、制作、工业和流程。
- 作品：内容、形式、叙事、体验和审美。
- 传播：媒介、平台、渠道、国际流动。
- 接受：受众、参与、社群、文化、市场。
- 价值与治理：文化价值、政策、伦理和行业治理。
- 历史演进：概念史、媒介史、创作史和产业史。

不要平均铺开所有角度。根据问法挑选最能回答题目的三至四个，并检查：

- 分论点是否处于相近层级；
- 是否相互重复或存在包含关系；
- 排列是否形成递进、因果、流程、正反或由微观到宏观的逻辑；
- 合在一起能否完整支撑中心论点，而非三个孤立话题。

## 三层结构

### 宏观：全文

- 标题指向中心论点或核心问题。
- 引论完成必要背景、概念界定和中心论点。
- 正论采用三至四个板块，每个板块承担明确任务。
- 结尾总结并回扣题目，在材料基础上适度提升。

### 中观：板块与段落

每个板块通常包含：

1. 小标题或分论点；
2. 论点阐释；
3. 一个深入案例，或两个比较案例，或若干简短并列案例；
4. 对案例的机制分析；
5. 本段结论、题目回扣或承上启下。

一个板块可分一至两段。是否分段由论证关系决定，不按固定句数切割。

### 微观：句子

- 主旨句应是能够被论证的判断，不只是“某某方面”。
- 关联词必须反映真实关系，不为了显得有逻辑而滥用。
- 理论术语首次出现时给出必要解释。
- 避免空泛形容、同义反复和过度华丽表达。

## 段落论证标准

最小有效单元是：

```text
分论点 → 论据 → 为什么能证明 → 回到题目
```

案例不能只说明“发生了什么”。至少补充一层机制、因果、比较、意义或限度分析。理论不能只报学者姓名；必须说明它解释了材料中的什么现象。

展开段落前，先用论证单元检查：分论点是否覆盖任务、材料是否匹配、论证桥梁是否成立、结论是否回到题目。缺少论证桥梁时，不得以增加案例数量代替分析。

## 训练方法

- **结构标记**：标出中心论点、分论点、证据、论证和回扣，检查是否缺环。
- **压缩与扩展**：把专题压缩成考场版，再把提纲扩展成完整论证。
- **转述训练**：把论文观点改写成准确、简洁、可手写的表达。
- **专题迁移**：同一材料分别用于不同问法和院校方向，检查其适用边界。
- **反馈闭环**：批改不仅改句子，还要回到审题、角度选择和材料理解，定位认知缺口。

## 防止模板化

- 不强制每篇都以“近年来＋数据”开头。
- 不强制每篇都是三个对称标题。
- 不为工整而牺牲任务覆盖或真实逻辑。
- 标题与小标题是功能模板，不是固定措辞模板。
- 结尾不机械重复全文，应完成总结、回扣和必要提升。
