# 专题卡与论文提取

## 目标

论文整理不是生成摘要，而是把论文转化成可以回答真题、构成专题和进入考场答案的材料。专题卡与答案使用相同的分析框架。

## 单篇论文提取

阅读论文时提取：

1. **来源信息**：题名、作者、年份、刊物或文档位置。
2. **论文问题**：作者试图解释、评价或解决什么问题。
3. **核心结论**：用一至三句写出作者的中心判断。
4. **概念与边界**：概念定义、易混概念、适用范围。
5. **论证结构**：作者用了哪些分论点，它们是什么关系。
6. **材料**：作品、案例、数据、政策、历史事实。
7. **机制分析**：材料为什么支持结论，而不只是列出案例。
8. **限制与争议**：条件、反例、作者未解决的问题。
9. **考场转写**：可直接使用的简洁观点、案例句和评述句。
10. **可回答题目**：这篇论文能支撑哪些可检索子问题和真题。

明确区分作者原观点、论文所引观点、案例事实和整理者推论。

提取完成后至少做一次可用性检查：每个保留项都应能落入“子问题—材料单元—候选论证单元”链路。只能复述论文内容、却无法说明能回答什么题的条目，移入背景备查，不进入核心专题卡。

## 材料单元

将论文拆成可复用材料单元，每个单元记录：

```text
材料编号：
主专题：
可回答的子问题：
原始观点或材料：
考场转写：
可支撑的分论点：
适用对象和条件：
来源定位：
核验状态：
关联专题：
```

一个材料单元只承载一个主要判断。相同观点合并，不因来自多篇论文而重复堆叠。

## 专题卡结构

### 1. 专题身份

- 专题名称、别名、主专题域；
- 研究对象、分析阶段、理论视角、考试路由和时效标签；
- 专题边界：包括什么、不包括什么。

### 2. 基础层

- 核心概念定义；
- 易混概念辨析；
- 发展历程和关键转折；
- 必须掌握的稳定知识点。

### 3. 问题层

按题目需要建立可检索子问题：

- 是什么、有哪些特征；
- 为什么产生、通过什么机制运行；
- 对创制、作品、传播、接受和价值治理有何影响；
- 有哪些矛盾、风险、挑战；
- 应采取什么路径，未来趋势如何；
- 与邻接专题如何比较或组合。

### 4. 观点层

- 中心判断；
- 正面机制或价值；
- 负面风险与限度；
- 矛盾关系；
- 发展和治理路径；
- 可替换的三至四组分论点方案。

### 5. 材料层

- 深描案例：适合一个段落重点分析；
- 并列案例：用于补充广度或比较；
- 理论工具：说明能解释什么，不只列人名；
- 政策、报告和数据；
- 每项材料的来源定位和核验状态。

### 6. 输出层

- 名词解释版本；
- 简答版本；
- 论述提纲；
- 精简考场版可写表达；
- 扩展复习版内容；
- 可迁移真题和自拟题。

## 合并多篇论文

1. 先按可检索子问题归类，不按论文顺序拼接摘要。
2. 对相同观点去重，选择表述最清楚、来源最可靠的版本。
3. 对不同观点说明差异来自对象、时间、方法还是立场。
4. 案例与理论分别建立索引，再与分论点绑定。
5. 当前数据和新作品单独标注日期，防止旧材料冒充最新现状。
6. 最后以真题反向检查：专题是否能生成中心论点、分论点、论据和论证。

合并后的专题应维护两种关系：

- **问题索引**：子问题 → 可用材料单元；用于检索与补缺。
- **论证索引**：候选分论点 → 材料单元 → 论证桥梁；用于提纲与成文。

专题不预制唯一答案。同一组材料可以形成不同论证单元，但每种组合都必须重新检查题目任务、适用对象和证明关系。

## 讲解学术概念

按用户理解程度选择深度，通常依次说明：

1. 一句话定义；
2. 它试图解释什么问题；
3. 核心机制或特征；
4. 与相近概念的区别；
5. 影视或数媒案例；
6. 在考研答案中的用法与误用风险。

不要用更多术语解释术语。若概念本身存在争议，展示主要口径和适用语境。
